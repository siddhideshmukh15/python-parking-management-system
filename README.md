# 🚗 Parking Management System

A simple **Parking Management System** built using Python. This beginner-friendly project allows users to park vehicles, remove vehicles, view parked vehicles, and check available parking slots.

## ✨ Features

* 🚘 Park a vehicle
* 🅿️ Automatically assign parking slots
* 🚗 Remove a vehicle
* 📋 View parked vehicles
* 🔢 Check available parking slots
* 🚫 Prevent duplicate vehicle numbers
* ❌ Check if parking is full
* 🚪 Exit the system

## 🛠️ Technologies Used

* Python
* Dictionaries
* Loops
* Conditional Statements
* User Input

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd parking-management-system
```

3. Run the Python file:

```bash
python parking.py
```
